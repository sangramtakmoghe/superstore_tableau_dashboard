## 🎯 Project Objective

The objective of this project was to build an interactive dashboard that makes it easier to explore business performance across different categories, sub-categories, regions, states, segments, products, and time periods.

This project was also an opportunity for me to gain practical experience with Tableau and data visualization.

---

## 📌 Dashboard Features

The dashboard includes:

- Sales analysis by category
- Profit analysis by category
- Sales and profit analysis by sub-category
- State-wise analysis using maps
- Segment-wise analysis
- Sales and profit trends over time
- Top 5 products by sales
- Top 5 products by profit
- Interactive metric selection
- Region filtering
- Category filtering
- Year filtering
